# PlaceSense Three Role Login UI

React + Vite + Tailwind CSS frontend with separate Student, Admin, and Company login components.

Palette from your reference image:
- MES Royal Blue: `#293F82`
- MES Golden: `#D9B976`
- White: `#FFFFFF`

## Run
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the Vite local URL.

## Role files
- `src/StudentLogin.jsx`
- `src/AdminLogin.jsx`
- `src/CompanyLogin.jsx`

Shared files: `src/LoginFrame.jsx`, `src/styles.css`, `src/main.jsx`.
The top navigation lets you preview each role. This is frontend-only; it does not authenticate users or send credentials to a backend.
